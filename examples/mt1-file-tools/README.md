# إضافة أدوات الملفات

هذه إضافة مثال بصيغة Mi_Max Ai `.mt1` API v1.

لإنشاء الحزمة:
1. اضغط محتويات هذا المجلد في ZIP.
2. تأكد أن `manifest.json` في جذر الأرشيف.
3. غيّر الامتداد من `.zip` إلى `.mt1`.
4. ثبّتها من مدير الإضافات، ثم فعّلها وافتح الأداة.

تستخدم الإضافة عمليات المضيف المسموح بها فقط: معلومات الملف، SHA-256، معاينة Hex، معاينة نصية، والتعرف الأولي على ترويسة الملف.
